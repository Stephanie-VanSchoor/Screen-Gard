# 👁️ ScreenGuard Pro – Assistant visuel professionnel

**ScreenGuard Pro** est une application de bureau conçue pour prévenir la fatigue visuelle et améliorer votre bien-être au travail.  
Elle vous rappelle de faire des pauses régulières, propose des exercices adaptés et suit vos progrès.

---

## ✨ Fonctionnalités

- ⏱️ **Minuteur intelligent** : pause toutes les 20 minutes (réglable).
- 🧘 **Pauses actives** : exercices aléatoires (regarder au loin, s'étirer, boire de l'eau, squats, etc.).
- 🔊 **Alertes sonores** : sons intégrés (début de pause, tic-tac, avertissement).
- 📊 **Statistiques** : suivi du nombre de pauses totales et quotidiennes.
- 🎯 **Objectif quotidien** : 8 pauses recommandées par jour.
- 💾 **Sauvegarde automatique** : vos données sont conservées.
- 🖥️ **Interface moderne** : design épuré et intuitif.

---

## ⬇️ Installation

### Option 1 – Télécharger l'exécutable (recommandé)

1. Téléchargez le fichier `ScreenGuardPro.exe`.
2. Double-cliquez dessus pour lancer l'application.
3. **Aucune installation requise** – ni Python, ni bibliothèques.

### Option 2 – Exécuter le code source (pour développeurs)

1. Assurez-vous d'avoir Python 3.8+ installé.
2. Installez les dépendances :
   bash
   pip install pygame numpy

    Lancez le script :
    bash

    python screenguard_pro.py
